# Epic: Summary Screen for Group Pre-Orders 

## US-1: Readable and High-Contrast Summary Table Interface 

| **Epic** | Summary Screen for Group Pre-Orders |
| :--- | :--- |
| **US name** | Readable and High-Contrast Summary Table Interface |
| **Role** | Group Owner |
| **Description** | **As a** group owner, **I want to** see a clearly structured table/list of dishes with high contrast and large font, **so that I** can easily read the order details of the entire group from any device and under any lighting conditions. |the entire group from any device and under any lighting conditions.                     |

### Pre-conditions:
- The group owner is logged in.
- The table reservation has been successfully created (Reservation status = "Reserved").

### Acceptance Criteria (AC):
- Opening the summary view displays the consolidated group order as an organized, multi-block layout (Guest List, Dish List, and Total Cost).
- Primary text font size must be at least 16px across all mobile and desktop screen sizes.
- The text-to-background contrast ratio must meet or exceed the WCAG 2.1 AA standard (minimum 4.5:1) under any lighting condition or screen theme.
- The layout must dynamically adjust and remain readable without horizontal scrolling on standard mobile viewport widths (320px and above).

## US-2: Overview of Consolidated Itemized Order, Quantities, and Special Requests 

| **Epic** | Summary Screen for Group Pre-Orders |
| :--- | :--- |
| **US name** | Overview of Consolidated Itemized Order, Quantities, and Special Request |
| **Role** | Group Owner |
| **Description** | **As a** group owner, **I want to** view a consolidated summary list of all selected dishes with details (number of servings, special requests, and allergens), **so that I** can quickly identify food shortages or unaddressed dietary restrictions of guests.                     |

### Pre-conditions:
- The group owner is logged in.
- The table reservation has been successfully created (Reservation status = "Reserved").

### Acceptance Criteria (AC):
- Identical menu items chosen by multiple guests must automatically aggregate into a single row displaying the total item quantity (e.g., "Four Cheese Pizza — 4 pcs.").
- Expanding a dish or guest entry must display all associated special requests, custom notes, and allergen warnings entered by guests.
- Special requests and allergen notes must be visually highlighted using dedicated accent indicators (e.g., orange or red tooltip icons).
- The overall summary must display an updated real-time total count of participating guests alongside their individual order status.

## US-3: Quick Editing and Addition of Menu Items by Organizer. 

| **Epic** | Summary Screen for Group Pre-Orders |
| :--- | :--- |
| **US name** | Quick Editing and Addition of Menu Items by Organizer |
| **Role** | Group Owner |
| **Description** | **As a** group owner, **I want to** be able to change dish quantities or add shared items (e.g., drinks for the whole table) directly from the summary screen, **so that I** can promptly adjust the order if the total amount of food is insufficient for the group.                   |

### Pre-conditions:
- The group owner is logged in.
- The table reservation has been successfully created (Reservation status = "Reserved").

### Acceptance Criteria (AC):
- Clicking the "+" or "-" buttons next to any dish instantly updates the item quantity and recalculates the total order price without requiring a page reload.
- Clicking the "Add to table" button opens a quick menu modal search, allowing the Group Owner to add shared items directly to a dedicated "Shared Order" category.
- Clicking the "Delete" icon (trash bin) next to an item prompts a confirmation modal; upon confirmation, the item is removed from the summary and the total price updates immediately.
- Any manual modification made by the Group Owner must immediately sync across the aggregated summary screen.
